# v1.1.3

修复调用方自动推导维护分支时把 `1.10b1` 等完整修复版本当作分支，导致漏洞范围无法编译的问题。

- 新增 `NormalizeInferredFixedBranch`，合法分支原样返回；仅将带后缀的非法自动分支转换为数字主版本，例如 `1.10b1`、`1.10rc1` 转为 `1.10`。
- 合法的字母补丁分支（例如 `2.10s`）继续保留，不扩大到整个数字分支。完整修复版本由调用方保留，仍作为排他修复边界。
- 仅供自动推导分支使用；`Compile` 对显式分支的错误校验保持不变。不透明标识、无法解析的输入返回错误，由调用方继续按原有流程处理。
- 不修改版本排序、范围开闭边界、MatchMain、OS 原生算法、Git/custom 或现有 r 标签支持；不处理数字修订区间逆序问题。

验证：全部包测试、竞态检查和 go vet，覆盖非法分支校正、合法分支兼容、修复版本排他边界、分支隔离及显式分支错误校验。
