新增 `github.com/yanqin001/version-compare/versionrange` 子包，将显式分类的发布版本比较集中到公共库。

- 提供 `Classification`、`NewComparator`、`Compare`、`ValidateRange` 和 `InBranch`，支持数字、日历、SemVer、Python、Maven、Go、npm、Cargo、NuGet、RubyGems、Composer 和 OS 原生规则。
- 支持固定版本前后缀、自定义标签顺序及发布标签别名，结构化边界不再经过通用表达式解析器。
- `GIT/UNKNOWN`、未知自定义标签和完整 commit ID 保持不可比较，不推测 Git 祖先关系。
- 比较器复制调用方配置，可并发复用；非法分类、版本及范围通过可检查的错误返回。
- 根包和 `osversion` 的旧 API、默认匹配语义保持兼容。新 `Compare` 返回 `-1/0/1`，旧 `VersionSvc.Compare` 继续返回 `0/1/2`。

最低 Go 版本调整为 **1.23.4**。生态比较使用固定版本 `deps.dev/util/semver v0.0.0-20261013100046-7bac2db56a63`；根包和 `osversion` 仍只使用标准库。

验证：完整测试、竞态检查、`go vet`，以及消费方 Intel 生成校验与 bind 分类/旧范围兼容测试。
