# v1.1.1

统一普通发布版本为 `normal`，解决历史标签 `v2.10s`、`v2.13-pre4` 以及 native 数字版本因上游 `v` 包装而无法比较的问题。

- `Classification.Canonical()` 将 numeric、release、semver、calver、go、npm、cargo、nuget、composer 归并为 normal，兼容读取这些历史名称。
- normal 复用通用解析，完整比较数字段、补丁字母和后缀，序号按数值比较，不再限制 alpha/beta/rc 等后缀名称。
- normal 的固定包装改为可选规范化提示；继续支持 r 标签和 stable/final/ga/custom 正式版别名。
- pep440、maven、rubygems、dpkg、rpm、apk、alpm、custom 保留专用规则，Git/UNKNOWN 和完整提交保持不可排序。
- 根包的项目 MatchMain 门禁、严格区间语义、OS 版本算法和已有接口不变。

注意：九个历史普通分类统一后的排序不再等价于各生态的严格规则。例如 rc10 晚于 rc2，+build 后缀参与比较。坐标区间始终完整比较后缀；项目门禁仍由调用方显式设置 MatchMain。

验证：全部包测试、CGO 竞态检查与 go vet；新增历史分类合并、字母补丁、任意预发布后缀、可选包装和项目门禁回归。
